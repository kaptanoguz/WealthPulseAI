# WealthPulse AI 📊

Modern financial asset management platform. Live market data, portfolio tracking, income/expense management, economic news, and Monte Carlo simulation — all in a clean desktop app.

## Features

- **Live market data** — quotes, charts, watchlists
- **Portfolio management** — holdings, P&L, allocation
- **Income / expense tracking** — cashflow insights
- **Economic news** feed
- **Monte Carlo simulation** — forward-looking scenarios
- **Multi-theme** UI

## Tech

- **Frontend:** Next.js (React) + TypeScript
- **Desktop:** Electron shell
- **Backend:** API routes (Next.js)

## Download

- **Windows:** `WealthPulseAI Setup.exe` from Releases
- **Linux:** `.deb` / `.AppImage`
